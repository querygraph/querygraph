QueryGraph with Pinax

Enterprise contracts for governed agent reads

Alexy Khrabrov, QueryGraph, September 2026

Introduce Pinax as the table-contract layer. The cover artwork belongs to the Pinax repository. The technical implementation uses Rust 2024. This presentation covers a prepared integration source build, not a claim that every execution extension is released.

What Pinax adds

A reviewed contract accompanies the table through discovery, planning and result release

  • Stable field IDs, types and business semantics
  • Owner, steward and exact policy binding
  • Compatible revisions checked against a predecessor
  • Catalog schema and registry pins checked at use
Source: Pinax src/model.rs, src/registry.rs and docs/pinax.md. Retention and primary-key declarations need enforcement by lifecycle and ingestion systems. Classification does not grant access.

The request cannot choose a storage path or policy engine.

Revision two

A reviewed optional column becomes a controlled consumer cutover

  1. Close consumers for the old registry
  2. Apply the reviewed target and reconcile catalog pins
  3. Start consumers pinned to the target digest
  4. Read real rows under revision two

Activation is an observation. The operator owns the maintenance window.

Source: integration/pinax/execute_rows.py and run.py. The recorded EC2 execution fixture passed real_rows_after_reviewed_consumer_cutover. The separate deployment fixture covers full registry creation/reconciliation and stale activation rejection. No distributed publication transaction is claimed.

Stateless MCP · 2026-07-28

  • Per-request context; no modern initialization handshake
  • Central ontology discovery over stdio and HTTP
  • Explicit model handles keep conversations separate
  • Up to 16 requests; disconnect cancels its HTTP work

A completed response cannot be retracted. Remote HTTP work may continue after local cancellation.

Sources: docs/mcp-stateless.md, src/mcp/http.rs and separate transport tests. Modern HTTP, direct stdio and Python handoff passed on grust; captured wire results validate against the official 2026-07-28 schema. Legacy stdio remains compatible. MCP endpoint: loopback 18082/mcp.
