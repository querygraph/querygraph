Sail + LakeCat
1 · A lakehouse with a schema
Sail executes reads over Iceberg and Parquet. LakeCat catalogs the table and its snapshot. Inspect the synthetic customer table’s physical schema and a fresh catalog-backed plan.
Pinax
2 · Standard table shapes
A large company needs common definitions for customers, employees, and transactions across teams. Generate Pinax’s typed profiles with stable field IDs, ownership, and semantic terms. This previews templates; it does not create new lakehouse tables.
Pinax + TypeSec
3 · Find the registered tables
The agent has an authenticated TypeSec identity and an analytics purpose. Ask Pinax which registered tables and fields it can use, with their types, owner, and steward.
Pinax ontology
4 · Find data by meaning
Consult the company’s reviewed vocabulary. Resolve Customer identifier to the physical field rows.id. Aliases such as account number let agents find the same meaning without knowing a column name.
MCP + QueryGraph
5 · Let an agent use MCP
Discover tools, resolve account number through Pinax, derive the field from the match, and execute the read over the live MCP HTTP endpoint. TypeSec signs the agent’s requests.
LakeCat + Sail
6 · Inspect the selected operation
Follow the discovered field into a scan plan. The plan names the table, projection, purpose, and current snapshot before execution.
Sail + Pinax
7 · Read the table
Read the selected identifier from real Parquet data. The result includes rows, provenance, and Croissant/CDIF semantic exports tied to the shared ontology.
Grust + Sail
8 · Connect the data as a graph
Load two dataset descriptions, their files and semantic links into a Grust graph stored through Sail. Read a node back and append workflow lineage.
Marciana + QueryGraph
9 · Describe data for other agents
Build the Navigator bundle: Croissant fields, CDIF data elements, vocabulary references, identity, and usage terms. The workflow consults the central ontology first.
Marciana + TypeSec
10 · Coordinate specialist agents
Run the Resilience Desk: a supervisor delegates to finance, energy, mobility, climate-health, and reference specialists, then combines their signed summaries. This is a deterministic agent-workflow fixture.
