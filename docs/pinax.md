# Pinax — Typesafe Enterprise Lakehouse Registry

Pinax has moved to the standalone [Pinax repository](https://github.com/querygraph/pinax).
Its authoritative [v1 specification](https://github.com/querygraph/pinax/blob/main/docs/pinax.md)
and [examples](https://github.com/querygraph/pinax/tree/main/examples/pinax)
are maintained there.

QueryGraph consumes the released standalone crate and retains its Rust compatibility path,
`querygraph pinax` commands, and `validate_pinax` MCP tool. See
[Pinax and QueryGraph touchpoints](frqg.md) for ownership, shared contracts,
service composition, and release coordination.
