# Fihrist — Typesafe Enterprise Lakehouse Registry

Fihrist has moved to the standalone [Fihrist repository](https://github.com/querygraph/fihrist).
Its authoritative [v1 specification](https://github.com/querygraph/fihrist/blob/main/docs/fihrist.md)
and [examples](https://github.com/querygraph/fihrist/tree/main/examples/fihrist)
are maintained there.

QueryGraph consumes the released standalone crate and retains its Rust compatibility path,
`querygraph fihrist` commands, and `validate_fihrist` MCP tool. See
[Fihrist and QueryGraph touchpoints](fr-gq.md) for ownership, shared contracts,
service composition, and release coordination.
